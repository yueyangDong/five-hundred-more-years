# v13 · 事件配图恢复：把「第一版配图」和「水墨画」分清楚

> 一句话：上一版把**要撤的**和**要留的**搞反了。撤掉的应该是 v10 之前那套矢量场景画，
> 留下的应该是 v10 引入的 9 张水墨位图。本文记录怎么发现的、怎么改回来的。

---

## 1. 现象

上一版上线后，事件卡里的画从这样：

```
屋舍、林木、山石、云雾 —— 一张完整的水墨写意，浓淡分明，占满 152px 画心
```

变成了这样：

```
一个窗框 + 一轮月亮 + 几个点 —— 像一张线稿示意图
```

一句「水墨画怎么没有了」，就是这件事。

---

## 2. 根因：需求原文里「第一版配图」指的不是水墨画

需求原文第四句：

> 事件的配图需撤掉第一版原有的全部配图，**只保留水墨画风格**，
> 并将事件中出现的水墨画画面做得更细致、更精细，使其贴合对应事件的内容。

当时读成了「撤掉全部画面，改用矢量水墨现画」。但这句话本身有个不能忽略的前提 ——
**「事件中出现的**水墨画**画面」**：它假定事件里**本来就有**水墨画，而且要把它做得更细。
所以「第一版配图」和「水墨画」是**两样东西**，不是一样。

用 `git log` 逐版数内联位图，两样东西立刻分开了：

| 版本 | 提交 | `data:image/` 内联位图 | 旧矢量场景画 |
|---|---|---|---|
| v7～v9 | `8ee75c6` … `c315780` | 0（只有金箔装饰） | **`sceneSVG` 有** ← **这就是「第一版配图」** |
| **v10** | `fffa122` | **23**（首次加入 9 张水墨底图） | `sceneSVG` 仍有 |
| v11 / v11.1 | `40d79e2` / `3105a18` | 23 | `sceneSVG` 仍有（两层叠加） |
| ~~v12~~ | `1dbea8f` | **14**（少了 9） | **0**（连水墨画一起删了） |
| **v13** | `ce4f5a5` | **23**（9 张一张不少） | 0（按需求撤掉） |

**结论**：v10 的 9 张水墨底图才是「水墨画」，v7～v9 就存在的 `sceneSVG` 才是「第一版配图」。

### 两层是怎么叠的

v11 的画面其实是两层：

```
<div class="scene has-art art-home">     ← 位图铺在 ::before 上（v10 的水墨画）
    <svg> … sceneSVG(cat, sub, key) …    ← 矢量场景画，opacity .32 + multiply，当墨线点睛
</div>
```

`sceneSVG` 在 `has-art` 生效时被压到 0.32 透明度、混色 `multiply`，只留一层"笔意"叠在水墨画上。
撤掉它，画面不会空 —— 只是把点睛那层去掉，反而更干净。这也正是「**只**保留水墨画风格」的字面意思。

## 4. 最终画面机制

一张内联 WebP 底图，铺在画心的 `::before` 上：

```css
.scene.has-art{height:152px;background:none;isolation:isolate}
.scene.has-art::before{
  content:"";position:absolute;inset:0;z-index:0;
  background-image:var(--art);
  background-size:cover;background-position:center 42%;background-repeat:no-repeat;
  background-color:#f2e9d7;
}
```

选图是**两层优先**：先看 `sceneKey` 命中的具体意象（考场→读书、婚事→红妆），
落空再看事件类目（健康→药庐、危机→沙场）；职业线额外按已立身之道分。
九张图分别是 `study` `court` `market` `home` `clinic` `journey` `winter` `war` `wedding`。

深色主题不重画，只压暗：

```css
:root[data-theme="dark"] .scene.has-art::before{filter:brightness(.60) saturate(.74) contrast(1.06)}
```

仍是「一幅画，只是入了夜」。

## 6. 验证（`_v13.js`，页面错误 0 / 断言失败 0）

**画面本身**（这一版的核心断言）

- 画心 `class = "scene has-art art-home"`，高度 **152px**；
- `--art` 解析为 **23490 字符**的 `url("data:image/webp;base64,UklGRr…")`；
- `getComputedStyle(scene,'::before').backgroundImage` 确实是个 `data:image/`，
  `background-size: cover` —— 证明浏览器真的把它当图铺开了，而不是「变量没定义、静默变空白」；
- `scene.querySelectorAll('svg').length === 0` 且 `innerHTML.length === 0`
  —— 画心里真的只剩那张图。

**其余三项**（与 v12 同口径）

- 按钮零涡：11 个按钮 × 悬停/按下，`#vx` 画布不透明像素 **0**；
- 投胎帖：十一个字段 + 层级（弹窗 60 < 帖 66 < 隧道 68）+ 「此时尚未开始」全过；
- 时光隧道：换屏 1346ms、峰值 172800px、本体末 2690ms、整层熄灭 **0px / max 0**、
  动画钟跑满 2.368/2.35、主线程 1.2s 内 rAF 217 帧。

**三端**

- 浅色：画心 506×152，底图正常；
- 深色：底图 + `brightness(.6) saturate(.74) contrast(1.06)`；
- 手机：画心 364×152，同样是一张水墨底图。

**线上**

发布后抓 `https://yueyangdong.github.io/five-hundred-more-years/index.html` 复核：
`gc-art` 与 `.scene.has-art::before{` 在位，`sceneSVG` / `initVxVortex` / `sc-ink` 全为 0。

## 7. 还没做完的那半句

需求第四句有三个动作，v13 完成了前两个：

- ✅ 撤掉第一版原有的全部配图（`sceneSVG` / `SCENE_ART_*` 那套画面）
- ✅ 只保留水墨画风格（9 张位图原样回来，画心里不再叠别的东西）
- ⬜ **把水墨画做得更细致、更精细，使其贴合对应事件的内容**

第三条现在还是 v10 的原样：**9 张图对 18 个类目 + 20 个关键词**。
「科举与赶考同一幅、药庐与卧床同一幅」这个问题仍然存在。

要真正做完，只有一条路：**把画面数从 9 扩上去**。两条可选：

1. **按关键词补画**：20 个关键词各出一张（+20 张 ≈ +360 KB 内联后约 +480 KB），
   映射从「9 选 1」变成「29 选 1」；
2. **按事件补画**：236 条事件各自成图（体积不可行），或折中到 36～48 张。

代价与画风一致性都需要先定，等确认后再动。
