## 这是什么

一个把「八字命理」当作**游戏数值系统**来用的文字人生模拟器。

命盘不是用来算命的，而是用来**给角色的初始属性加权、给事件池打权重**的。你出生时的四柱、五行分布、十神倾向，决定你这一生的起手牌和更容易撞上什么事件。

- 输入生辰（时辰未知可随机起时）或直接随一盘
- 生成八字角色卡：四柱、五行雷达、十神、日主强弱、喜用神
- 0 岁开始逐年推进，每年 2–3 个事件，每个事件 2–4 个选择
- 寿元耗尽 / 天年已尽 / 特殊事件 → 死亡结算
- 结算后进入轮回：保留命魂与天赋碎片，下一世更强

## 玩法

### 核心循环

```
投胎（输入/随机生辰）
   ↓
命盘页（看四柱、五行、十神、大运轴、角色卡）
   ↓
择一「本世志向」── 求富贵 / 求声名 / 求自在 / 求心安
   ↓
人生页（0 岁 → 死亡，逐年事件选择）
   ↓
结算页（寿命、评级、结局称号、墓志铭、命理复盘、生命轨迹图）
   ↓
轮回页（命魂入账、天赋树升级、图鉴收集）
   ↓
再来一世
```

### 暂离与续玩

人生不必一口气走完。

- 人生页底部有「**暂离 · 存档并回首页**」，随时可以走。每次选择都会落盘，直接关掉页面也不会丢。
- 下次打开页面，首页会出现「**未了之世**」卡片，写着你的命盘、当前年龄与本世志向，点「继续这一世」就能接着往下活。
- 卡片上还有「放弃此世 · 重新投胎」，会在二次确认后删掉进度（账本里的命魂、天赋碎片与图鉴不受影响）。
- 存档写在浏览器本地（`localStorage`），不上传任何服务器。清除站点数据会一并清掉存档。
- 一世了结进入结算后，存档自动清除，不会和下一世混淆。

### 出世之路：遁入空门

人生不只有往上走一条路，也可以转身走出去。

人生途中会遇上「**遁入空门**」的契机——佛门、道门、在家修行、或者摇头走开，四个选择。这不是一条普通事件，而是**一整条人生路线**：

- 一旦落发或入道，身份从「在俗」切换为「佛门」或「道门」，并随机取一个法号／道号
- **人间那套账不再按月结算**：事业、财富、时代类事件权重降到一成，情感、家庭淡到三成半；相对的，方外与修行类事件显著上升
- 年度耗损被改写——佛门 ×0.86、道门 ×0.76（道家重养生，更耐老）
- 每年自动获得本门所长：佛门涨功德与心性，道门涨心性、健康与机缘；代价是财富、名望、情感的自然流失
- **中途可以还俗**，但本世修行前功尽弃，并留下「退转」的标签；还俗过的人再想回头，门槛更高

佛道两途的终局也不同：佛门称「圆寂」，道门称「羽化」，各有专属结局。走到极处，是 **`一代高僧`**、**`得道真人`**，以及极难达成的 **`白日飞升`** 与 **`肉身菩萨`**。

> 这条路线只借用「出世」这一人生选择作为叙事框架，不涉及任何宗教劝导；所有内容均为虚构娱乐。

### 属性系统

12 项属性，初始值 20–80，由五行分布、日主强弱、十神倾向加权生成：

| 属性 | 含义 |
|---|---|
| 寿元 | 生命剩余额度，归零即死 |
| 健康 | 影响年度耗损速率 |
| 心智 | 判断力与定力 |
| 学识 | 知识积累 |
| 财富 | 资产 |
| 事业 | 社会成就 |
| 名望 | 声名 |
| 情感 | 亲密关系 |
| 机缘 | 运气与巧合 |
| 功德 | 正向积累 |
| 业力 | 负向积累，高企会反噬 |
| 心性 | 内在修养 |

### 八字 → 游戏规则的映射

| 命理元素 | 游戏作用 |
|---|---|
| 日主天干 | 核心性格与成长曲线 |
| 月令季节 | 出身环境与早期资源 |
| 五行分布 | 属性雷达与强弱项 |
| 十神倾向 | 事件池偏向（正印=学习贵人、七杀=竞争危机、偏财=投资社交……） |
| 日主强弱 | 强则主动，弱则借势 |
| 喜用神 | 幸运策略与补足方向 |
| 刑冲合害 | 冲突、贵人、关系危机 |

五行语义：**金**=决断/规则/财富，**木**=成长/学习/仁心，**水**=智慧/流动/情感，**火**=行动/名声/热情，**土**=稳定/健康/包容。

### 结局

共 **18 种**结局称号：

`富甲一方`、`权倾朝野`、`隐居悟道`、`江湖散人`、`早逝天才`、`孤苦终老`、`名垂青史`、`德被苍生`、`业火焚身`、`大限圆满`、`平凡一生`，以及跨越轮回的终极结局 **`打破命簿`**；

出世路线另有 5 种：**`一代高僧`**、**`得道真人`**、**`青灯古佛`**、**`肉身菩萨`**、**`白日飞升`**。

## 特色机制

### 大运与流年

- **大运**：每 10 年一柱，阳年男/阴年女顺行，十神定主题（正官、七杀、偏财、正印……）
- **流年**：流年干支的五行落在喜用神还是忌神上，直接修正当年事件权重
- **流年宜忌**：人生页顶部实时显示当年的「宜」与「忌」

### 本世志向（双轨目标）

开局四选一，相关事件更容易找上门。达成度**决定评级上限**——完全走岔了路，分数再高也上不去。

### 轮回系统

- 命魂：每世评分累积
- 天赋碎片：评分折算，用于点亮天赋树（9 条天赋，含「洞悉天机」永久显示选项数值）
- 天赋**抬高属性上限**而非简单加值，避免后期收益被递减机制吃掉
- 图鉴：结局 18 种 + 事件全收集

### 数值平衡

属性不是简单加减，而是三层机制共同作用：

1. **高位阻尼**——属性越接近上限，正向收益越小
2. **属性天花板**——天赋决定各属性的可达上限
3. **年度自然回归**——极端值会被拉回，避免单一属性一路封顶

业力另有**消散机制**（受功德影响），防止只增不减导致必然反噬。

## 技术实现

### 排盘引擎

不查固定日期表，而是**真算节气时刻**：

- 用 Meeus 太阳视黄经公式求解「黄经到达 15° 整数倍」的真实时刻
- 十二节交节时刻精度实测误差 **3–6 分钟**
- 年柱以**真实立春时刻**为界，月柱以**真实十二节时刻**为界
- 日柱用儒略日数推算，时柱用五鼠遁

> 例：2024 立春算得 16:21（实际 16:26）。同日早 8 点生 → 乙丑月，晚 8 点生 → 丙寅月。

同时计算：六十甲子纳音、生肖、星座、地支藏干加权五行、十神、日主强弱、喜用神、六合六冲相害三刑自刑。

> 说明：节气换柱点是准的，但整体仍是**游戏化简化**，不声称真实排盘。

### 事件系统

事件为 JSON 结构化配置，权重动态计算：

```
事件权重 = 基础权重
         + 命盘修正（日主 / 十神 / 五行 / 大运 / 流年）
         + 玩家标签修正
         + 属性状态修正
         + 志向契合修正
```

内置 **148 条事件**，覆盖：家庭、学业、事业、财富、情感、健康、机缘、危机、修行、日常、晚年、时代、**方外**。

其中「时代」类事件按公历年份开窗，会随出生年代不同而触发不同内容；「方外」类则按当前身份（在俗／佛门／道门）开合，是出世路线的专属内容。

带 5 年冷却，防重复。

### 视觉表现

- 背景浮尘粒子 canvas
- 页面切换卷轴展开动画、卡片错峰入场
- 四柱翻牌、五行雷达生长动画
- **事件卡按 13 个类别生成不同 SVG 场景插画**（屋舍/书卷/楼阁/方孔钱/双环桃枝/竹/星芒卦象/惊雷/莲花/茶盏/松鹤/楼群/孤灯，方外另有佛塔莲台、太极丹炉、山门三式）
- 属性变化浮动数字
- 结算页生命轨迹四线图（状态/余寿/功德/业力）
- 结局称号揭示动画 + 朱印落下
- 宣纸质感与云纹边框

### 分享

Canvas 生成 750×1240 命盘海报（四柱、结局称号、属性条、标签、时间线），支持保存与一键复制文案。

### 技术栈

原生 HTML + CSS + JavaScript，**零依赖、零构建**。存档走 `localStorage`，出生信息本地计算优先。

## 本地开发

改 `index.html` 即可，刷新浏览器生效。

**做数值平衡调试**，可以搭无头模拟器：把 `<script>` 内容抽出来在 Node 里跑几百世，用分位数看寿命/评分/结局的真实分布，而不是靠手玩几次拍脑袋调参。

要点：用 `vm.runInContext` + 桩化 `document` / `localStorage` / `setTimeout`，并在脚本尾部追加 `globalThis.__T = { G, META, ... }` 显式暴露 `const` 词法绑定（`const` 不会自动挂到 sandbox 上）。
