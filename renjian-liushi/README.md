> 室、财、子、禄、寿、誉。六事皆求，终不能全。
> 五世只给你**一个八字**。第一世你看不见它，第五世它才开口。

## 三条核心规则

**一、六事取 min，不求和；而且这六样你看不见。**
一岁十二个月令，每件事都要占格。所有"无法兼得"最终都能还原成"今年这十二格，你给了谁"。结算不看你赢了多少，只看你最薄的那一块。

左栏六行只有虚线——**数字、彩条一概没有**，加减只报 ↑/↓。只有**任意一格推到 100**，才会「透」：六事俱明，全盘亮起。看清自己的唯一方式，是把一件事做到没人能装作没看见。

**二、五世同一个八字，古或今不由你挑。**
八字在开局前生成一次，跨局锁定——不随出身、时代、职业改变。变的只有壳：生在哪家、生在哪年、你选了哪条路。古代窗口取**嘉靖前后各五十年（1494—1594）**，以嘉靖五年（1526，丙戌）为卷首之年；现代取"现在"（2020—2032）。每局独立掷，但**五局古今各不少于二**。

**生在哪家，也不是你挑的。** 十二种出身随机一张牌，揭开来是什么就是什么——能挑，就会退化成难度选择，而"这局抽到了罪臣之后"才是它该给你的东西。

**三、第一世看不见自己。**
六才（智、体、言、巧、忍、缘）永不以数字示人。你只能从"事办得顺不顺"里反推，而反推出来的印象记在**手记**里——**手记可能是错的**。第五世结算，命书才开。

## 玩

直接用浏览器打开 `index.html`。存档在 localStorage，`清卷` 可重来。**声音默认开着，但浏览器要先等你点一下**——第一次点击之后才有声；右下角的 `音` / `静` 可随时关。

- 掷局 → **投胎**（生在谁家，由不得你挑）→ 每折（四年）选一项 → 局末得三句手记 → 五局毕出命书 → 摸到自己的顶，可窥天机

### 评审直链

| 参数 | 作用 |
|---|---|
| `?static=1` | 关掉全部动效（无头截图用）；**同时静音** |
| `?demo=roll` | 掷局屏 |
| `?demo=life` / `?demo=life&era=mo` | 一局中（古 / 今） |
| `?demo=hand` | 局末手记 |
| `?screen=book` | 命书 |
| `?screen=tianji` | 天机 |
| `?dev=1&screen=hub` | 预置四局已成的五局盘 |
| `?auto=1` | 自动通关五局，结果写进 `#testOut[data-test]` |
| `?auto=1&smart=1&strat=cai\|home` | 专精 / 顾家两种自动策略，用于配平验证 |

## 原型范围

**已实现**：八字生成（年柱按月柱五虎遁、日干定主才、月令定旺衰、五行计数封顶）、六才隐藏成长、**六事全隐与「透」（一格到 100 才全亮）**、五局随机古今、六事与月令、**三十条事件（古今两套文案、每条三选项一记手记）**、**子的五级台阶（有后/立业/有孙/家和/四世同堂）、誉的一极即满与方外之路、律的暗线（问拟/立案、首告、出家）**、三关、手记（含"错误的记忆"）、命书、天机、改史与跨世已知、**三记音效（掷局/透/卒，WebAudio 现场合成，右下角可关）**、单机存档。

**未实现（见设定框架 §11）**：六轨计分与史评五笔法完整版、情关四种、事后账簿三年回响、同榜 NPC 党争网、企业线与市井十二行、满招损反噬。

**原型数值为示意**，正式版需逐条配平。排盘为简化算法（日柱随机取值），接真实节气与万年历是正式版的事。

## 设计上两处被原型推翻的规则

1. **寿不参与 min**。寿归 0 就是死，不是"缺寿"；若把 0 算进 min，每个结局都是"空"。
2. **天机不是"必须 95"**。按八字规则能出现 95 的命只占 9%，改成"**摸到自己的顶**（上限 ≥78）"，才不是抽奖；95 那一格只多一行朱批。

## 参考与致谢（GitHub）

写完这一版后对照了两个开源项目，各借了一条，也各推掉了一条：

| 项目 | 是什么 | 借了什么 / 没借什么 |
|---|---|---|
| [VickScarlet/lifeRestart](https://github.com/VickScarlet/lifeRestart)（MIT，10.4k ★） | 《人生重开模拟器》：1500+ 事件、五属性（颜值/智力/体质/家境/快乐）、天赋继承 | **借：每条事件带年龄区间。** 这次审查抓到的最大的一个错——`致仕`（退休）没有年龄门槛，十六岁就能被抽到。现在 30 条事件全部带 `minAge/maxAge`，官方事务另加 `minLu`（白身不该被"京察"）。**没借：属性体系与"全程不可操作"**——它是观察者日记，我们要的是每一次选择都留下代价 |
| [6tail/lunar-javascript](https://github.com/6tail/lunar-javascript)（MIT，零依赖） | 节气 / 干支 / 八字 / 十神 / 纳音全解 | **本该借、暂未借**：本作月柱按农历月取、日柱随机，接它才是真排盘。单文件零依赖的原型阶段先不引，正式版第一件事就是换它 |

差距也很清楚：它是 1500 条事件、无选择；我们是 30 条、条条双时代（明嘉靖 / 当代）+ 三选项 + 一句手记。**数量不是这一版的胜负手，分寸才是。**
