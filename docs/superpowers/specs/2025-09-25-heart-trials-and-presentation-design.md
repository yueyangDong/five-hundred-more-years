# 问心局 · 选项分层呈现 · 配图与特效增强 设计

- 日期：2025-09-25
- 起因：玩家反馈「选项太多不耐烦、太杂」「想要问心局那种纠结矛盾」「特效单调」「事件配图太简单」

## 0. 现状（实测数据）

| 项 | 现状 |
| --- | --- |
| 事件数 | 92 条（`EVENTS`），选项 365 个 |
| 选项数分布 | **91 条是固定 4 选项**，1 条为 1 选项 |
| 每年事件 | `beginYear()` 里 `n = 2 + rnd(2)`，即 2~3 个/年 |
| 抽取 | `rollEvents()` 按 `weightOf(ev)` 加权随机；`noRoll` 字段的事件权重为 0（因果链专属） |
| 权重 | 中位 13，88 条 <20，最高 60；稀有由 `w <= 7` 判定 |
| 选项数值 | **一律不预览**，选完才揭晓（`renderLife` 注释：「选了之后才揭晓」）——保留 |
| 配图 | `sceneKey()` 关键词匹配出 17 类 → `sceneSVG(cat, sub, key)`；`sub` 字段零使用 |
| 特效 | ripple / flash / sparks / pathAura / willAura / bgFx 六种 |

## 1. 决策（均经用户确认）

1. **问心局独立新增**，不改现有 92 条事件与数值平衡。
2. **「小事 2 项、大事 3 项」只做分层「呈现」**：不删选项、不改数值、不改触发。
3. 配图扩到 30+ 情境；特效分层增强。

## 2. 问心局

**不进抽取池**。问心局放独立的 `HEART` 数组，不加入 `EVENTS`，因此 `rollEvents` 的加权抽取、净贡献、`_rate.js` 口径全部不变。由 `beginYear()` 在关口额外插入。

- 结构复用现有事件形状，`opts` 固定 2 条，直接走 `chooseOption` → `doChoose` → `renderResult` 现有链路：
  `{id:'h01', kind:'heart', cat:'问心', title, desc, age:[a,b], cond:{}, opts:[{t,r,e,tg},{t,r,e,tg}]}`
- **触发**：`rollHeart()` —— 年龄 ≥10 岁起、同世内同一问心局不重复（复用 `G.usedAt`，无需新增存档字段）、两次问心间隔 ≥12 年、优先落在大运交接年。
- **内容原则**：不写「一好一坏」，写「两条路都要失去点什么」。两个选项的收益量级相当、代价方向不同，没有支配解。
- **视觉**：专属卡型 `.event.heart` —— 两条路左右对峙、中间一道裂痕、专属墨色配图；选项仍是 `.opt`（复用现有选择链路）。

## 3. 分层呈现

- 判据：`影响力 = Σ|e[k]|`，配合类别修正 → 小事 / 大事。
- 小事默认露 **2** 个选项，大事露 **3** 个，问心局固定 **2** 个。
- 其余收在「再看看」里，**保持原始顺序**（不按优劣排序，否则等于剧透；也不随机）。
- 数值、触发、平衡一律不变 —— 变的只是「一次要读几个」。

## 4. 配图 17 → 32 种情境

保留现有 17 类，新增：`mountain` `river` `wall` `court` `workshop` `school` `train` `city` `factory` `prison` `famine` `lamp` `mirror` `well` `shrine`。

同时补光影层次：近景 / 中景 / 远景分离，天光随时段变化。仍全部由 SVG 原生动画承载，不占用 JS 线程。

## 5. 特效分层

- 按事件类别给专属氛围（不再只有「稀有金光 / 危机红光」两种）。
- 属性浮动数字按属性语义分色（成长类 / 消耗类 / 业力类）。
- 关键节点一次性仪式感：大运交接、志向达成、轮回结算。

## 6. 平衡与兼容

- 不改 `EVENTS` 任何一条数据；不改 `weightOf` / `rollEvents` / `applyEffect` / `dampen`。
- 不新增存档字段（复用 `G.usedAt`）；旧存档可继续读取。
- 所有新增状态走现有 `G` 字段，`saveRun()` 无需改动。

## 7. 验证

Chrome headless 实渲染：问心局卡型、分层呈现（默认 2/3 项 + 展开）、新增配图、特效分层各截一张；
并用探针对「现有事件仍在、选项数不变、问心局不进 EVENTS」做断言。
