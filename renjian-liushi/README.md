# 人间六事 · 五世

> 室、财、子、禄、寿、誉。六事皆求，终不能全。
> 五世只给你**一个八字**。第一世你看不见它，第五世它才开口。

一款以明代嘉靖前后百年与当代为背景的人生模拟游戏。**设定框架 + 可玩原型**。

## 三条核心规则

**一、六事取 min，不求和。**
一岁十二个月令，每件事都要占格。所有"无法兼得"最终都能还原成"今年这十二格，你给了谁"。结算不看你赢了多少，只看你最薄的那一块。

**二、五世同一个八字，古或今不由你挑。**
八字在开局前生成一次，跨局锁定——不随出身、时代、职业改变。变的只有壳：生在哪家、生在哪年、你选了哪条路。古代窗口取**嘉靖前后各五十年（1494—1594）**，以嘉靖五年（1526，丙戌）为卷首之年；现代取"现在"（2020—2032）。每局独立掷，但**五局古今各不少于二**。

**三、第一世看不见自己。**
六才（智、体、言、巧、忍、缘）永不以数字示人。你只能从"事办得顺不顺"里反推，而反推出来的印象记在**手记**里——**手记可能是错的**。第五世结算，命书才开。

## 玩

直接用浏览器打开 `index.html`。存档在 localStorage，`清卷` 可重来。

- 掷局 → 选出身 → 每折（四年）选一项 → 局末得三句手记 → 五局毕出命书 → 摸到自己的顶，可窥天机

| 参数 | 作用 |

## 原型范围

**已实现**：八字生成（年柱按月柱五虎遁、日干定主才、月令定旺衰、五行计数封顶）、六才隐藏成长、五局随机古今、六事与月令、十一类事件（古今两套文案）、三关、手记（含"错误的记忆"）、命书、天机、改史与跨世已知、单机存档。

**未实现（见设定框架 §11）**：六轨计分与史评五笔法完整版、情关四种、事后账簿三年回响、同榜 NPC 党争网、企业线与市井十二行、满招损反噬。

**原型数值为示意**，正式版需逐条配平。排盘为简化算法（日柱随机取值），接真实节气与万年历是正式版的事。

## 设计上两处被原型推翻的规则

1. **寿不参与 min**。寿归 0 就是死，不是"缺寿"；若把 0 算进 min，每个结局都是"空"。
2. **天机不是"必须 95"**。按八字规则能出现 95 的命只占 9%，改成"**摸到自己的顶**（上限 ≥78）"，才不是抽奖；95 那一格只多一行朱批。
