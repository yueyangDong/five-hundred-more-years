# 《人间六事》设定框架

> **室**、财、子、禄、寿、誉。
> 六事皆求，终不能全。这不是数值平衡，是设定本身。
>
> 民间旧说「妻财子禄寿」。本作把"妻"放宽成**「室」**——有没有一个你愿意回去的地方。可以是妻，可以是老母，可以是一个义子、一个同住的朋友，也可以**一辈子没有**。单身不是缺一项，是换一套算法。
>
> 官场那一层，学《大明王朝 1566》：**没有坏人，只有各为其位的人**。每个人都在办一件他认为对的事，而这几件事互相要命。但你**不是**海瑞，也**不是**严嵩——同一榜进士、同一个翰林院，出去的人分成了十几条路。你不扮演谁，你在选，最后史书把你归到哪一本传里。
>
> 而这一切，五世只给你**一个八字**。第一世你看不见它，第五世它才开口——**命不动，人动。**

---

## 0. 五条原则

| # | 原则 | 具体做法 |
|---|---|---|
| 一 | **六事不同源** | 六项不是六条进度条，来源、画法、衰减方式各不相同。看不清来源，才谈得上取舍。 |
| 二 | **时间是唯一的硬约束** | 一岁十二个月令，每件事都要占格。所有"无法兼得"最终都能还原成"今年这十二格，你给了谁"。 |
| 三 | **没有干净的选项** | 每个选项都有人受损，区别只是"谁受损、什么时候还"。玩家不做道德判断，只做欠账排序。 |
| 四 | **角色不是给的，是选出来的** | 起点相同（同榜、同馆），轨由一次次站边累计；死后的史评决定你被写进哪一本传——包括"无传"。 |
| 五 | **命不动，人动** | 同一个八字，五世不换；换的只有出身、时代与选择。**第一世看不见自己的命，第五世才给命书。**（见 §2） |

## 1. 六事：室、财、子、禄、寿、誉

### 1.1 定义与量纲

六项统一 0–100，但**语义完全不同**，禁止用同一套 UI 表达。

| 项 | 全称 | 是什么（不是什么） | 0 的含义 | 100 的含义 |
|---|---|---|---|---|
| **室** | 家室 | 有没有一个你愿意回去、也愿意等你回去的地方。**不是"有没有配偶"** | 无人可归（不等于失败） | 有人等你吃饭，且你愿意回去 |
| **财** | 家底 | **可支配**的家底，不是年收入 | 典尽当绝 | 银钱通神，说话有人听 |
| **子** | 子嗣 | "有没有"×"成不成器"×"亲不亲"三者合成 | 无后；或子已断绝 | 子承其志，且愿意回来吃饭 |
| **禄** | 位 | **组织授予的位置**及随之而来的稳定俸给、身份 | 白身 | 一人之下 |
| **寿** | 元气 | 余年。唯一**单向递减**、不可回补的一项 | 死 | 老而不衰 |
| **誉** | 名声 | 双轴：**清誉**（干净）与**能名**（办得成事），二者常相反 | 声名狼藉 | 天下称之 |

#### 「室」的五条路径

不必成婚。**「室」只问一件事：有没有人等你回去。** 五条路径都能把它填到 70 以上，各有各的代价：

| 路径 | 上限 | 代价 | 备注 |
|---|---|---|---|
| **婚配** | 100 | 占月令、牵动门第、牵动党争（妻族即关系网，也是软肋） | 主流路径 |
| **孝养**（与父母同住） | 80 | 父母在，不远游：外任/调防判定 −20；丁忧必至 | 独身者最稳的一条 |
| **义子 / 养子 / 过继** | 75 | 需要先在「子」上投入；族中会争"这是谁家的香火" | 与「子」项部分重叠，不算双份 |
| **挚友共爨**（友人同住，明代实有） | 70 | 誉 −5（"两个男人过一辈子"的闲话）；一方先死，另一方骤归 0 | 文人、僧人、幕友常见 |
| **门生侍疾**（老了有学生养） | 65 | 须一生在「誉」上不断投入；门生会卷入你的党争 | 讲学、座师路线 |

**五条路径可以叠加，但只取最高的一条 + 其余各按 1/3 折算**——一个人可以有妻、有老母、有义子，但"回去的地方"只有一个，分值不叠加。

#### 「无室」档：单身一辈子

选「无室」不是放弃这一项，是**把它从结算里摘出去**：

- **六事按五项结算**（财、子、禄、寿、誉 取 min）。
- 其余五项**上限各 +5**（无所牵挂，所以每一件都能做得更狠）。
- 每年多 **2 个月令**（无家累）。
- 解锁**「孤臣」轨**（见 §4）：无党、无妻族、只有上意与民心——1566 里最硬的一种人，也是最容易被弃的一种人。

**前提**：五条路径一条都不取。所以要么父母已不在、又终身不婚；要么主动与家里**断了往来**——后者另记一笔：誉 −5、宿命线加重（"弃养"这两个字会跟着你一辈子，考成、弹章、史评都会翻出来）。

代价（必须真疼，否则人人独身）：

| 代价 | 机制 |
|---|---|
| 无人照料 | 寿 年损 +1；「病」事件无照料判定，−15 |
| 无人可托 | 身后事：卒后若 子 = 0 且 室 = 0，丧仪降一等，誉 结算 −10（"无后"） |
| 老年独坐 | 60 岁后每年触发一次「独坐」事件：可花 1 月令会友（财 −5），不花则 寿 −2 |
| 无人劝你 | 「墨」的**退还事件触发率减半**（没人拦你），贪念更难回头 |

> 这一档不是"困难模式"，是**另一种活法**：你可以一辈子不娶，把十二格全给公务，做到尚书；也可以在六十岁那年，一个人坐在空院子里，听见隔壁人家在吃饭。


**誉 的双轴**（这一条是官场线的核心）：

```
清誉：别人信不信你干净        能名：别人信不信你办得成
清高而无人用 = 清流            能办而人不服 = 能吏 / 酷吏
```

两项都高极难，因为**办事必得罪人，不得罪人必办不成事**。游戏里 `誉` 的显示永远是两个小字：「清」与「能」，各自一个刻度；综合值只用于结算。

**财 的刻度换算**（让数字有意义）：

| 财 | 白话 | 一两银子 ≈ |
|---|---|---|
| 0–20 | 温饱：这个月够，下个月不知道 | 三十斤米 |
| 20–40 | 小康：能供一个读书人 | — |
| 40–60 | 殷实：置得起二十亩田 | — |
| 60–80 | 富：县里排得上号 | — |
| 80–100 | 巨富：钱已经不是钱，是别人的眼红 | — |

### 1.2 三种稀缺机制

「不能全得」不能靠"数值调得紧"，要靠**三条结构性规则**。

#### A. 月令制（最硬的一条）

一岁 = **十二个月令**。每月令只能落一件主事。

| 事 | 每年必须投入 | 不投的后果 |
|---|---|---|
| 营生 / 公务（禄） | 4–6 格 | 考成下下，三年不进则退 |
| 归家 | 1–2 格 | 室 −8～12（逐年累加） |
| 教子 | 1–3 格（子 6 岁后） | 子 −5，且"不亲"标记一旦落下不可撤 |
| 养身 | 1 格 | 寿 −3；40 岁后翻倍 |
| 交游 / 应酬 | 1–2 格 | 情报断（事件里"找谁打听"的选项消失） |
| 谋财（平民线） | 6–8 格 | 财不增，全家挨饿 |

**账算不平**：仕途线 4+1+1+2 = 8，剩 4 格；教子要 2 格，养身要 1 格——你今年只能顾一头。
平民线 6–8 格谋生，剩 4–6 格，室与子只能选一个。
**无室档少一栏**：没有「归家」，多出的 1–2 格可以全给公务或养身——但没有人会在你病的时候递一碗水。

> 这就是整个游戏的核心张力：**不是"想不想要"，是"今年这十二格给谁"。**

#### B. 边际递减 + 交叉惩罚

- 单项投入的收益递减：从 60 涨到 70 要 2 格，70 到 80 要 4 格，80 以上每 +1 要 1 格且**别项每年 −2**。
- 所以 **80 是软墙**：过了 80，你是在拿别的项换这 1 点。

#### C. 满招损（>85 的反噬）

| 项 | >85 触发 | 后果 |
|---|---|---|
| 禄 | 树大招风 | 每年 15% 弹章；落马则禄归 0、财 −40 |
| 财 | 招祸 | 绑票 / 抄家 / 分家，誉 −10 |
| 誉 | 谤随 | 每年一次"揭伪"，誉 −20 回落 |
| 室 | 家人开始怕失去你 | 查岗、翻你的行李、夜里等你回来，寿 −2 |
| 子 | 早慧易折 / 骄纵 | 20% 触发"子病"或"子讼" |
| 寿 | 孤 | 同辈皆死，室、友、子 各 −5 |

**「六全」结局的门槛**：六项 min ≥ 60 且无一项 >85。理论上存在，实操上要放弃所有"再往上一点"的诱惑——这正是留给二周目的。

### 1.3 张力矩阵（十五对）

六项两两之间都有方向，没有一对是无关的。这是"取舍"能被玩家算出来的原因。

| 对 | 方向 | 机制 |
|---|---|---|
| 禄 → 誉 | 负 | 每升一级清誉 −5（做事必得罪人）；清誉 >80 时升迁判定 −15（"清流不可用"） |
| 誉 → 财 | 负 | 清誉 >80，灰色收入全关，财年增 −50% |
| 财 → 誉 | 负 | 财年增 >+20 的年份，誉 −3（"他的钱哪来的"） |
| 禄 → 寿 | 负 | 每赴一任 / 升一级，寿 −2；连续三年无休，寿 −5 |
| 禄 → 室 | 负 | 每升一级，室 −4（"你又调走了"）。成婚者更狠：妻族替你选，也替你得罪人 |
| 财 → 室 | 正转负 | 财 <20：室 −5/年（贫贱夫妻）；财 >60：每 +10，归家月令需求 +1（富了，但更见不着） |
| 子 → 财 | 负 | 教子占格；子不肖则财 −10/年（败家） |
| 子 → 禄 | 负 | 子病、子讼，禄判定 −10（"家门不清"） |
| 誉 → 子 | 负 | 誉 >80，子承压：子才学 −10（"你儿子不如你"） |
| 室 → 寿 | 正 | 室 >70：寿年损 −1（有人管你吃饭睡觉） |
| 室 → 誉 | 负 | 婚配对象门第低于你两档：誉 −2/年（"他娶了个村妇"）；独身另有一笔：60 岁后 誉 −1/年（"这人怪"） |
| 财 → 子 | 正 | 财 >50 可请名师：子 +5/年 |
| 禄 → 财 | 正 | 禄是财的主源（俸 + 陋规 + 门生） |
| 誉 → 禄 | 正（迟） | 誉 >70，在"需要名声"的岗位上考成 +10；在"需要办事"的岗位上 −10 |
| 寿 → 一切 | 分母 | 寿 <30：十二格变九格（做什么都慢） |

**用得最多的一条**：禄升得越快，室与寿同时掉。这就是"仕途"这件事的定价。

### 1.4 结算：取最短的那块板

终局不求和，取 **min(六项)**。

**「无室」档按五项结算**（财、子、禄、寿、誉）——单身者的算式里，本来就没有这一项，不该被它判负。

**「寿」不参与 min。** 寿归 0 就是死，不是"缺寿"——若把 0 算进去，每个人的结局都会是"空"，这套算式就废了。寿另算：`卒年 ≥ 60` 全额，`40–60` 折半，`<40` 才拉低结算（早死是真罚）。**死亡是结局，不是短板。**

| min | 判词 | 墓志起句 |
|---|---|---|
| 0–20 | 你赢了很多，但缺的那一样，把其余的都说成空的 | 「某某，某地人。……」 |
| 20–40 | 你过得去，只是每一样都差一口气 | 同上，加「无所成，亦无所失」 |
| 40–60 | 寻常人的一生，六样都不算亏 | 「乡里称善人」 |
| 60–85 | 少见的圆满。但你比谁都清楚代价 | 「六事俱全，而终身不乐」 |
| ≥60 且无项 >85 | **六全** | 「此卷可焚」 |

再加三句：
- 一句取自**最高项**——"别人记住你的方式"。
- 一句取自**你最常做的那个动作**（系统统计三十年里的高频操作：签、等、送、拖、借）——"你自己是什么人"。
- 一句取自**史评**（见 §5.5）——"后人把你归进了哪一本传"。

**结算顺序**：先出六项 min，再出史评，最后出墓志三句。**先给分，后给话**——因为人总是先被评判，再被解释。

## 2. 八字：五世同一个，死前才看见

> 六事是**账**，八字是**本钱**。
> 账可以天天看，本钱不给你看。
> 你一辈子都在猜自己是什么材料——**猜错是常态，猜对是运气。五世之后，命书才开。**

### 2.1 三条硬规则

| # | 规则 | 做法 |
|---|---|---|
| 一 | **第一世，什么也不显示** | 八字不入 UI、不进存档面板、不给提示条。你只能从"事办得顺不顺"里反推。反推出来的印象记在「手记」里，**而手记可能是错的**（见 2.8）。 |
| 二 | **五世同一个八字** | 八字在开局前生成一次，之后**跨局锁定**——不随出身、时代、职业改变。变的只有壳：生在哪家、生在哪年、你选了哪条路。**否则"选择"就没有意义。** |
| 三 | **第五世结算，命书才出** | 五局走完，出具「命书」：四柱、六才、哪一格终身不过六十、哪一格可以到顶、三个关分别落在哪一年。若五局中任一项曾触**顶级（95）**，命书后再开一页：**八字格局 · 窥天机**（见 2.9）。 |

设定上的解释（与前作共用同一句话）：**一魂五世。** 魂是形，八字是形的纹路，五百年不换；父母、时代、门第，只是它穿过的五件衣裳。

### 2.2 六才：本钱

六事是"得到什么"，六才是"凭什么得到"。六才统一 0–100，**除命书那一页外，永不以数字示人**。

| 才 | 是什么 | 验在哪 | 缺了会怎样 |
|---|---|---|---|
| **智** | 读书、算账、料事 | 科考、钱粮、刑名、看折子 | 考不上；看不着三步以后（事件里"预判"类选项消失） |
| **体** | 筋骨、耐久、扛得住 | 军务、长途、熬夜、连任 | 一累就病，寿年损 +1；武职判定 −20 |
| **言** | 辞令、人望、说服 | 奏对、讲学、结党、托人 | 话说不到位，"托人"白托；弹章辩不过 |
| **巧** | 手艺、数目、办事的具体门道 | 工程、营造、作坊、商贾、账 | 只能发号令，办不成具体的事 |
| **忍** | 承压、久任、能屈 | 谪贬、拖、等、被人踩 | 一次挫折就改轨（改轨判定必败） |
| **缘** | 识人、情分、得人死力 | 情关、门生、同僚、妻族 | 看不懂人，站错边；终身无"替你说话的人" |

**六才不直接加六事。** 它只改两样：**判定修正**与**兑换率**——同一件事，智高的人花 1 格，智低的人花 2 格。天资的全部表现，就是"**你办这件事，贵不贵**"。

### 2.3 八字怎么长出六才

四柱八字（年、月、日、时各一干一支），先落五行，再定旺衰，最后分到六才。三步，能算，不玄。

**第一步 · 数五行。** 八字共 8 字（甲乙木、丙丁火、戊己土、庚辛金、壬癸水；寅卯木、巳午火、辰戌丑未土、申酉金、亥子水）。

| 某一行出现次数 | 该项上限 |
|---|---|
| 0 个（缺） | **58**（−20）——这是"哪方面不行"的唯一来源 |
| 1 个（弱） | 70（−8） |
| 2–3 个（平） | 78（基准） |
| 4 个以上（旺） | 88（+10），并触发「偏」（见 2.10） |

**第二步 · 日干定主才。** 日干是你本人；五行分到六才，用的是同一张表（缘不在五行里，见下）。

| 日干 | 主才 | 一句理由（够用即可） |
|---|---|---|
| 甲、乙（木） | **智** | 木主条达，生长不息，读书之象 |
| 丙、丁（火） | **言** | 火主文明显扬，辞令之象 |
| 戊、己（土） | **忍** | 土主厚载，久任之象 |
| 庚、辛（金） | **体** | 金主刚锐，筋骨决断之象 |
| 壬、癸（水） | **巧** | 水主流通机变，数目之象 |

**缘**不在五行里，在**合冲**里：四柱地支每有一对"六合"，缘 +12；每有一对"六冲"，缘 −12。基准 60，下限 5——**缘是唯一可能一开局就不及格、且可能为负增长的一才。**

**第三步 · 月令定旺衰（只对主才）。** 日干生于月支，**同我（比劫）或生我（印）者为得时，上限 +15；其余为失时，−15**。

于是全部上限封在 95。**这就是整套八字系统里最关键的一道算术：**

> 78 + 10（旺）+ 15（得时）= 103 → 封顶 **95**。
> 也就是说：**能到"顶级"的，只有"日干与月令同气、且该行在八字里出现四次以上"的那一格——唯一的、注定的、放不过的那一格。**
> 其余最好的一格，最多 93。**差那两点，就是一世。**

（原型阶段可先不做地支合冲全表：地支按序固定 3 处关年，并只实现"子午、丑未、寅申、卯酉、辰戌、巳亥"六冲与"子丑、寅亥、卯戌、辰酉、巳申、午未"六合。）

### 2.4 三个关（应期）

八字里定**三个年龄**，各有一个关，三段分布：

| 关 | 年龄段 | 试哪一才 | 过 | 不过 |
|---|---|---|---|---|
| **第一关** | 25–35 | **主才** | 主才判定 +5（**上限已封 95 者只吃判定**），并解锁一项"别人没有的选项" | 主才锁 70（此后一切靠主才的事都差一口气） |
| **第二关** | 40–50 | **最弱的那一才** | 最弱才上限 +10（**最多补到 78 为止**，缺仍是缺，只是不那么缺了） | 六事中随机两项 −8，「偏」加重 |
| **第三关** | 55–65 | **缘** | 卒后史评上浮一笔（门生替你说话） | 无传——「时同僚有某者」 |

**设计意图一句话说清**：**第一关考你的长处，第二关考你的短处，第三关考你这辈子有没有对人好过。** 前两关是命，第三关是自己攒的。

**难在"你不知道哪年"**：第一世全盲；第二世起，上一世死在哪一年，那一带会被标一个淡淡的墨点；第四世起，前三个关以"你总觉得三十一岁那年，路窄"的口气写进手记。

### 2.5 五局：只换壳，不换命

一局 = 一世 = 16 岁到死。五局共用一个八字，其余全可换——**但时代不由你挑，每局掷古或今（见 2.6）**。

| 局 | 你能看见什么 | 可换什么 | 设计意图 |
|---|---|---|---|
| **一** | 什么也没有。六才、上限、关，全隐藏 | 出身 / 职业线（时代随机） | **纯手感**。你靠"顺不顺"活一辈子，死时只知道"我好像不太会算账" |
| **二** | 上一世留下的三句「手记」（可能错） | 出身 / 职业线（时代随机） | 第一次有对照：同一个人，生在官宦家 vs 生在匠户家 |
| **三** | 手记累积五条，出现"倾向"（"你经手账目，很少出错"）——**仍无数值** | 同上 | 玩家开始主动做实验：这一世专试「忍」 |
| **四** | 上一世三个关的年份被标出（墨点） | 同上 | 第一次能提前布局——也第一次尝到"躲得过关，躲不过缺的那一项" |
| **五** | 前四世手记全在手，且**互相矛盾** | 同上；这是最后一局 | 结算时命书出：五世的矛盾，一次说清 |

**同一八字，五种活法（示例）**

| 局 | 出身 | 职业线 | 轨 | 史评 | 一句话 |
|---|---|---|---|---|---|
| 一 | 军户 | 行伍 → 河工 | 能吏 | 附于《河渠志》后 | 「堤未溃」 |
| 二 | 官宦 | 翰林 → 御史 | 清流 | 本传 | 「你的话，比你的命长」 |
| 三 | 匠户 | 营造 → 县丞久任 | 循吏 | 循吏传 | 一县之祠，朝廷不知其名 |
| 四 | 富二代 | 盐商 → 捐官 | 权臣 | 佞幸传 | 富而无位，位而无终 |
| 五 | 父母双亡 | 白身 → 门生满天下 | （无传） | 无传 | 「时同僚有某者」 |

**五局不要求"通关"**。死得早也是数据：早死多半是「体」或「忍」缺，命书照写。

### 2.6 时代池：五世随机古今

**入局掷一枚，古或今，不由你挑。** 你想不到这一世生在哪一半——这是"命不动"的第二层：不只是材料不由你，**年月也不由你**。

#### 古代窗口：嘉靖居中，前后各五十年（1494—1594）

以**嘉靖五年（1526 丙戌）**为卷首之年，嘉靖一朝（1522—1566）居中，前后各留五十年，成一整百年。三段各有各的命：

| 段 | 年号纪年 | 起讫 | 世相 | 你能改什么 |
|---|---|---|---|---|
| **前段** | 弘治—正德 | 1494–1521 | 承平。朝上没人真在打仗，地方上兼并已成 | 改得动，**但你有生之年看不到结果**——这是对"改史"最狠的惩罚 |
| **中段** | 嘉靖 | 1522–1566 | 1566 正剧。改稻为桑、清丈田亩、河工银、倭乱、庚戌之变 | **改史的主战场**：每一件都是"必有人受损"的事 |
| **后段** | 隆庆—万历初 | 1567–1594 | 张居正十年。一条鞭法、考成法，能改的多，清算也快 | 改得动，但**你多半死在他倒台之前或之后**，两头都难看 |

**窗口不是背景板。** 同一个八字，生在前段是"你写的奏疏没人看"，生在中段是"你签的字要人命"，生在后段是"你办成的事三年后被推翻"。

#### 现代窗口：二〇二〇—二〇三二

不设内部三段——**现代只有一段，因为它太短，来不及分段**。取"现在"前后各若干年，事件只用这十几年里真会发生的事（烂尾、内涝、考编、裁员、学区、体检报告、父母住院）。

#### 掷法（三条硬约束）

| # | 约束 | 理由 |
|---|---|---|
| 一 | 每局独立掷 **50 : 50** | 随机感要真。玩家必须有过"我以为这世是古代，结果是现代"的经验 |
| 二 | **五局古今各不少于二** | 掷满了自然满足；若掷出 4:1 或 5:0，**最后一局强制补缺口**——四古一今的五行，讲不出"命不动，人动" |
| 三 | 具体年份在段内随机，**局起必为 16 岁** | 出生年 = 起局年 − 16。1526 起局者生于 1510（正德五年）；若生在中段，起局年就在 1538–1582 之间 |

**第五局额外一条**：若前四局古今比为 2:2，第五局照掷；若已 3:1，第五局补缺口。**总之最后一局永远是你活过的那一半，而不是你偏科的那一半。**

> 一句话：**古与今不是难度，是两种价目表。** 古代的禄可以传家，现代的禄可以跳槽；古代的誉要等死后三年，现代的誉一条短视频就能毁掉。同一副枷锁，换了一身衣裳——这是前作《仕途五百年》的做法，本作继续用。

### 2.7 改史：古代那一半可以被改写

**古代局里，历史不是既定的。** 你能救下一个本该死在嘉靖二十九年的人，能把一条本该失败的法推成，也能让一场本该打赢的仗打输。**改完，它就成为下一世的正史。**

#### 三条铁律

**① 人有算盘，不改。**
承接 §5.6：历史人物按自己的逻辑走，不会因为你是主角就绕路。**能改的从来不是"他为什么这么想"，是"他这一次有没有成"。**

**② 改史有账，三年后回收。**
每改一笔，记一笔**「史债」**。史债与"事后账"（§6）同源，但回收方式不同——它不在你身上回收，**在世界身上回收**：

> 你救下了那个人。三年后，顶他缺的那个人死了。
> 你把那条法推成了。三年后，靠这条法吃饭的人，成了新的祸。

**③ 改史跨五世。**
一魂五世，你记得。**改过的那一笔，写进下一世的底本**：第二世开局，卷首会多一行小字——

```
（此世已知：嘉靖二十九年，俺答未至。）
```

这一行是全作最恐怖的一行字。它意味着：**你上一世改对了，也可能改坏了，而这一世你得带着它活。**

#### 四级改动（能改多大，看你有多大）

| 级 | 你能动什么 | 代价 | 谁能动 |
|---|---|---|---|
| **微** | 一个人的生死 | 他活着，就顶了另一个人的缺——**那人死了**，且你不知道是谁 | 任何人，一次一局最多两笔 |
| **中** | 一件事的成败（堤修成 / 法推成 / 城守住） | 成败互换，但"谁签字"必须换人：**你失去一个靠山** | 禄 ≥40，且在该事上签过字 |
| **大** | 一朝的政策走向（改稻为桑成 / 一条鞭法早十年） | 誉 −15、墨 +20；**史评必被改写**，进《奸臣传》的概率翻倍 | 禄 ≥70，或在该朝有"不可抹去的事" |
| **极大** | 王朝的年限（"大明多活二十年"） | **命书改写：「此命不载」。** 你不再有墓志、不再有史评、不再有八字——系统只留一行"（此处原有一人）" | **只有第五局、且已窥天机**（见 2.9） |

#### 不能改的四样

天灾（旱涝、蝗、疫）、物价、别人的寿、**你自己的寿**。

> 最后一条最要紧：**你能改天下一百年，改不了自己那口气。** 改史改到最后，玩家会发现他一直在改别人的命，自己的命一格没动——这正是八字那套东西要说的。

#### 现代局：没有史，但有人

现代局不改史（没有"史"可改，只有"人"）。但**现代局改的人，会在古代局里留下一个回声**：

- 每局现代局，最多留**一处「回声」**：你救过、毁过、说服过的那个人，其姓名与一句话，会以**同名后人**的形式，出现在某一次古代局的一折里，只说一句话，且不加解释。
- 这个回声**不改变任何数值**——它只让玩家在第三次撞见那个名字时，手停一下。

> 古今随机最怕的是"两套游戏拼接"。这一段是防它的唯一办法：**让两半互相认得。**

### 2.8 手记：第一世唯一的线索

六才不给数字，给**句子**。每局结束，系统从这一生里挑三件事，写成三句第一人称的话，存进「手记」；**下一局开局写在卷首，随后消失。**

```
三十一岁，河道上，我三天看完了一年的账。            （智）
四十四岁，那封信我压了两个月，还是烧了。            （忍）
五十七岁，她没有等我。                              （缘）
```

（括号里的才名是给设计看的，**游戏里不出现**。手记只是三句白话。）

三条规矩：

1. **手记只能由"做过的事"生成**，不能由"属性"生成——没经过的事，不写。
2. **手记可以是错的。** 若某一才在八字里为「缺」，而玩家恰好走了替代路径（智缺却靠「言」办成了事），手记会写成"我很会办事"——**这是全作最重要的一次欺骗**：玩家带着一个错误的自我认知，去开下一局。
3. **五条为满**，之后同类句子替换旧的、不新增。第五局开局，五句话互相矛盾——**这时玩家才明白自己一直在猜。**

### 2.9 命书 · 窥天机

**第五局结算后，命书出。** 一页，竖排，全墨，唯一的红是那方印：

```
            四柱    丙午 · 甲午 · 丙寅 · 己丑
            ───────────────────────────────
            智  ▓▓▓▓▓▓▓▓░░   七十八      —
            体  ▓▓▓▓▓▓░░░░   五十八      终身不过六十
            言  ▓▓▓▓▓▓▓▓▓▓   九十五      可至顶（此命唯一一格）
            巧  ▓▓▓▓▓▓░░░░   五十八      终身不过六十
            忍  ▓▓▓▓▓▓▓▓░░   七十八      —
            缘  ▓▓▓▓▓▓░░░░   六十        五十七岁那一关，得自己过
            ───────────────────────────────
            三关    三十一 · 四十四 · 五十七
            此命    火得时，言独旺；金水俱缺。
```

这一页读完，五世就都解释通了：**为什么你每次都能把话说进人心里，却一辈子没算清过一笔账**——不是你不努力，是金与水，一个都没有。

> 六才一栏记的是**上限**，不是他做到了多少，是他最多能到多少。**命书从不夸人。**

然后是**窥天机**——五局中**任一才曾摸到它自己的上限**（该上限须 ≥78；缺格永远不算）便开。

> 为什么不是"必须 95"：这是原型跑出来的一个大坑。按八字规则，能出现 95 的命只占 **9%**——其余 91% 的玩家走完五世也开不了天机，那这一整套就成了抽奖。改成"摸到你自己的顶"之后，规则变成一句话：**你的顶不是别人的顶，但走到头就算数。** 95 那一格的特殊之处，只剩命书上会多一行朱批：**「此命唯一一格可至顶」**。
>
> 而"顶"能不能摸到，仍然只取决于八字：只有**天生最旺的那一格**（该行四现，初始值就高）才够得着上限，所以"补不上去的，天生就补不上去"。这才是要的。

各格局如下（下表按"摸到顶的那一才"取格局）：

| 格局 | 四柱特征 | 一句谶语 | 第六局给什么 |
|---|---|---|---|
| **伤官配印** | 日干弱、伤官旺、印星制之 | 「你的话，比你的命长。」 | 言类判定 +10；弹章必至，但每次都换来名 |
| **食神生财** | 食神旺、财星得地 | 「你手里过的东西，都会变多。」 | 财类"过一手"：财 +，誉 − 减半 |
| **羊刃驾杀** | 日干极旺、刃杀并见 | 「你只欠一场仗。」 | 边臣线全开；寿年损 −1（死得快，但不怕） |
| **官印相生** | 官星得地、印星护身 | 「你升得慢，但你一直在。」 | 考成永不落"下下"；升迁判定 −10（慢就是稳） |
| **从财格** | 日干无根、全局财旺 | 「人家求你，你不求人。」 | 商线起点 财 +20；禄 上限 −15（富而无位） |
| **偏印夺食** | 印重食轻 | 「你懂一切，只是做不成一件。」 | 每年可"先看一次底牌"；办事判定 −10 |
| **孤辰寡宿** | 地支合少冲多 | 「你要的东西，都得自己拿。」 | 直接进「无室」档且无代价；六项上限各 +5 |
| **中和格**（罕） | 五行各 1–2，无缺无旺 | 「你什么都能做，什么都做不响。」 | 无单项加成；六项软墙 80 → 85（唯一能稳拿「六全」的命） |

**「天机」只改信息，不改难度。**

1. **看得见**：第六局起，六才与上限常显——这是最大的一笔赏：从盲打变明打。
2. **择时**：开局可在时代池里挑具体年份，挑对则第一关提前两年（多一次准备）。
3. **补偏**：仅一次，把某一才的上限 +10（**最高 95，且不可补在已达 95 的那一格**）——**代价是另一才 −10，砍哪一个由玩家自己定。** 这是全套设定里唯一一次"能改命"，也是唯一一次"改命要割肉"。
4. 第六局结算仍取 `min(六项)`，**一分不让。**

> **中和格为什么也算开天机**：它的 95 从来不在某一才，而在"一局六事 min ≥70"。**唯一一条不靠天才、靠不出错的路。**（这一条是可选的慈悲；若嫌太宽，删掉即可，不影响主结构。）

### 2.10 与既有系统的七个接口

| 接口 | 关系 |
|---|---|
| **六事（§1）** | 六才是因，六事是果。才不加事，只改判定与兑换率——因果之间隔着**选择**，这就是五局的意义 |
| **出身（§3）** | 出身是**后天**：父母、家底、门第、宿命线；八字是**先天**：材料、上限、关。二者正交——**同一个八字，可以生在官宦家，也可以生在匠户家。五局里请务必各试一次**，那是这套设定最好看的地方 |
| **月令（§1.2）** | 八字**不改**月令总数（12 格，公平不动），只改"一格值多少"。**时间是唯一的硬约束，天资也得在这个约束里打折** |
| **轨（§5）** | 同一八字可走六轨。史评写"能吏"，命书写"你本是言官的材料"——**这是全作最狠的一句对照**，也是二周目的燃料 |
| **情关（§7）** | 情关四种都试「缘」。缘缺者 A 与 D 几乎必败；但缘缺也意味着"没人能拿你家里人要挟你"——**缺项在别处变成盔甲** |
| **墨（§6）** | 八字为「偏」者，墨涨得更快：**财旺者贪，禄旺者专，言旺者刻。** 偏就是软肋，软肋就是入口 |
| **结算（§1.4、§8）** | 命书**不改**结算。它只在最后给出二选一：「你这一生，是用错了才」，或者「才不够」 |

### 2.11 边界情况

| 情况 | 处理 |
|---|---|
| 某局死得太早（<25 岁） | 该局手记只写一句（"我还没弄明白"），**且不计入"五局"**——五局按"活到有结局"的局数计，避免刷 |
| 五局全走同一条轨 | 允许。命书多一行："你五次都做了同一种人。"——这不是批评，是一种结局 |
| 某局 min = 0 | 不影响命书；手记里写"那一年我把一件事做绝了" |
| 玩家想中途看八字 | 不给。**唯一能看的地方是第五局结算之后**——这是设定，不是权限 |
| 摸到顶要多久 | 一局 12 折（48 年），专精一处约 8 折可到 78；缺格与"未旺"的格，五世都到不了 |
| 到顶记录会不会被下一局冲掉 | 不会。才每局重算（初始值由八字定、由事件长），**到顶记录跨局保留**——第四局到顶也算 |
| 六才初始值 | `25 + 该行字数 × 8`（上限封顶），缘按合冲取 60±12。火四、水零的命，开局就是 言 57、巧 25 |

### 2.12 UI 语法：藏要藏干净，露要露得狠

- **藏**：第一局，六才在代码里存在，界面上**一个字都没有**。不给"未知属性"的问号，不给进度条，不给"???"——**问号本身就是暗示。** 全部反馈只走事件结算后的一句话。
- **露**：命书一页，竖排，四柱在上、六才在中（**墨线长短条，不用雷达图**——雷达图太"游戏"，条形更像命书上的批注）、三关在下，落一方朱印。
- **色**：命书**不用彩色**，全墨；唯一的红是那方印，和"终身不过六十"那一行的一笔朱。
- **音**：命书出现时**没有音效**。留白三秒，再出字。

一句总纲：**六事让你焦虑，八字让你认命，窥天机让你不甘心。** 三层情绪，正好撑得住五局。

## 3. 出身：四档十二种

出身不是"难度选择"，是**起手盘 + 隐性债务 + 一条会反复回来的宿命线**。

### 3.1 十二张出身卡

六项初值按 16 岁（可议亲、可入行）计。室 的初值是"已经有一段情分，或已经有一个要养的人"，不是"有没有对象"。

#### A 档 · 资源型

| 出身 | 室 | 财 | 子 | 禄 | 寿 | 誉（清/能） | 底色 | 宿命线 |
|---|---|---|---|---|---|---|---|---|
| **官宦子弟**（父四品） | 30 | 55 | 0 | 45 | 70 | 55/40 | 门第 +30：议亲可选高一档；人情世故 +20，事件中"托人"成功率高 | 父亲的政敌。你入仕第一天，就有人在等你的错 |
| **富二代**（盐商 / 布商之子） | 25 | 85 | 0 | 10 | 62 | 25/35 | 银钱通神：财类事件可花钱免判定；但誉类事件 −10（"他家的钱不干净"） | 分家。父在，你是少爷；父死，你是三房里的老大 |
| **书香门第**（父为举人 / 塾师） | 20 | 30 | 0 | 30 | 66 | 70/30 | 清誉高、财薄；财类事件判定 −15（不会来事，也不肯） | 父亲的功名未竟。你不考，就是不孝；你考不上，也是不孝 |
| **侨眷**（南洋有亲） | 15 | 60 | 0 | 15 | 68 | 40/45 | 退路：任一年可"下南洋"（财 +、誉 −）；但在 1952–1978 线会被反复审查 | 一封来自海外的信，和你不敢承认的那门亲戚 |

#### B 档 · 缺口型

| 出身 | 室 | 财 | 子 | 禄 | 寿 | 誉 | 底色 | 宿命线 |
|---|---|---|---|---|---|---|---|---|
| **单亲**（父亡母在 / 母亡父在） | 35 | 18 | 0 | 12 | 62 | 42/32 | 早熟：月令 +1（十三格）；代价是每年随机"家中有事"占 1 格 | 那一场病。你所有升迁的机会，都会撞上它 |
| **父母双亡**（族中寄养） | 0 | 5 | 0 | 10 | 58 | 30/30 | 无援：人情网络为空，事件里"找谁"的选项少一半；韧性：失败后恢复快（重来判定 +20） | 认祖归宗。你要找一个能叫"家"的地方，可能一辈子找不到 |
| **罪臣之后**（父辈罢官 / 抄没） | 10 | 25 | 0 | 0 | 66 | 15/45 | 原罪：一切审查类事件 −15；识人极准（从小看人脸色，读人 +25） | 翻案。或者改名换姓，从此不提父亲 |
| **重组家庭**（继父 / 继母） | 15 | 30 | 0 | 15 | 67 | 35/35 | 夹缝：家中资源要争，"分家"类事件必触发；极会做人（人情 +10） | 继弟争产。你争的是钱，也是"谁才是这家的儿子" |

#### C 档 · 底层型

| 出身 | 室 | 财 | 子 | 禄 | 寿 | 誉 | 底色 | 宿命线 |
|---|---|---|---|---|---|---|---|---|
| **匠户**（木 / 铁 / 瓦） | 20 | 35 | 0 | 5 | 70 | 40/50 | 手艺：工程、营造类事件 +15；可凭手艺入官营作坊（匠官，禄上限 40） | 脱籍。匠籍是世袭的，你的儿子一出生就在册上 |
| **农家 / 佃户** | 20 | 15 | 0 | 5 | 60 | 45/30 | 能忍：所有"拖"的选项效果 +30%；但月令永远少 1 格（农时） | 那一场旱。以及每年秋后，地主家的秤 |
| **市井小贩** | 15 | 25 | 0 | 0 | 63 | 25/45 | 消息灵：可花 1 月令买"内情"（事件真相提前一层）；无门第：议亲上限低两档 | 抽头。衙役、地痞、行头，三家轮着来 |
| **军户 / 退伍** | 15 | 20 | 0 | 20 | 58 | 50/40 | 敢动手：武力类判定 +20；读书线 −15（科考几乎无望） | 调防。一纸文书，把你从家门口调到三千里外 |

#### 三档不均衡的公平性

不追求"数值总和相等"——六项本来就不可通兑（一尺禄换不了一年寿）。公平靠**三层错位**：

| 层 | 资源型（官宦/富二代/书香/侨眷） | 缺口型（单亲/孤儿/罪臣/重组） | 底层型（匠户/农家/小贩/军户） |
|---|---|---|---|
| **起手高度** | 高（禄/财有底子） | 低（但有两项机制补偿，见「底色」列） | 中（有一门手艺或一门消息） |
| **上限** | 有天花板（官宦的禄到 80 就被"父党"卡住；富二代的誉很难过 60） | 上限高（孤儿没有父党可牵连，禄可至顶） | 偏窄（禄 40–50，但财/室容易满） |
| **代价** | 欠着人情与旧账（宿命线来得早、来得准） | 起步即负债（第一年就要"活下去"） | 一格永远被占（农时/营务/夜班） |

一句话：**资源型赢在前十年，缺口型赢在后二十年，底层型赢在"从没输过"的错觉里。** 这正是让玩家愿意重开的原因。

**"室"的初值按新定义重算**（有人等你回去，不是有没有配偶）：单亲 35（母亲在，相依为命，孝养路已开）、父母双亡 0、罪臣之后 10（家在，但破了，族人避你）、重组家庭 15（家里有人，但你不是"那个儿子"）、军户 15（常年在外，家书比人先到）。

### 3.2 出身的三种用法

1. **起手盘**：初值决定前五年能做什么（财 <20 的人，第一年只能选"活下去"）。
2. **隐性债务**：宿命线不是随机事件，是**必来**的。它会在你最高光的年份找上门——因为你越是往上走，越绕不开它。
3. **判定修正**：出身给的修正**不显示数字**，只在事件结算时以"某一句台词"出现：
   > 「你父亲当年……唉，不说了。」（罪臣之后，判定 −15）

### 3.3 出身 × 情关的门第差

议亲时有**门第**（1–5 档：白身、庶民、商户、士绅、官宦）。

- 门第差 ≥2 档：情关 D（现实压力）的"父母反对"必然触发。
- 门第差 ≥3 档：即使成婚，室 → 誉 每年 −2（族里、同僚、街坊都在说）。
- 出身低而 禄 高：可以"补门第"（禄每 20 点，门第 +1），但补得越晚，能选的人越少（年龄窗口）。

## 4. 职业：三条轴

> **职业是"干什么活"，轨是"被归到哪一类"。** 两者独立：能吏可以是知县，也可以是户部尚书；清流可以是御史，也可以是翰林侍讲。职业决定你每月做什么事，轨决定史书怎么看你（见 §4）。

### 4.1 三条主轴

| 轴 | 定义 | 六项偏向 | 特点 |
|---|---|---|---|
| **仕** | 有"位"的人：官、吏、军职、学官、医官 | 禄 ↑、誉 双向、财 中、寿 ↓ | 禄可被一次性剥夺；一切成败归"考成" |
| **商** | 企业、票号、工厂、公司 | 财 ↑、禄 ↑（职级）、誉 中、寿 ↓ | 禄 = 职级（见 3.2）；可"跳槽"，但每次跳，誉 −3 |
| **市** | 市井谋生，无禄或低禄 | 财 低而稳、寿 ↓、誉 低 | 没有位可挡事；但也没有位可丢 |

### 4.2 禄的定义（企业路线归禄）

> **禄 = 组织授予的位置。**

| 路线 | 禄的形态 | 上限 | 被剥夺的方式 |
|---|---|---|---|
| 仕途 | 品级（九品—一品） | 依出身上限（官宦 80，罪臣之后 30 至翻案） | 罢官、贬谪、丁忧去职 |
| 企业 | 职级（文书 → 主管 → 经理 → 总监 → 副总 → 总裁） | 无硬顶，但每级对应"离家的月令"递增 | 裁员、站错队、公司没了 |
| 军职 | 品级 + 兵权 | 60（非进士出身难至总兵） | 战败、削藩 |
| 教职 / 医官 | 学官、太医 | 50 | 学术获罪、医案 |
| **个体户 / 手艺人** | **无禄（禄 = 0）** | — | 不适用 |

**无禄路线的补偿**：禄 = 0 的人，财与誉的上限各 +10，且不受"弹章"体系影响。代价是：**任何一次官面上的事，你都没有"位"可挡**——一张告示就能让你的铺子关门。

> 这就是"宁做鸡头"的代价与好处，也是给不想卷的人留的一条路。

### 4.3 市井十二行（平民谋生）

每一行都给：门槛、年入（财）、寿损、可升路径、与官场的接口。

| 行 | 门槛 | 年入（财） | 寿 | 升 | 与官场的接口 |
|---|---|---|---|---|---|
| **脚夫 / 挑夫** | 无 | +3（温饱） | −2/年 | 把头 → 脚行行头 | 官物过境，抽头；也可替人夹带 |
| **船工 / 渡夫** | 会水 | +4 | −2 | 船主 → 船行 | 漕运、关卡：一张"船票"能通天 |
| **更夫** | 无 | +2 | −3（夜） | 更夫头 | 巡夜即耳目，是衙门最便宜的线人 |
| **屠户** | 胆 | +6 | −1 | 肉铺 → 行头 | 官宴采买；年节"送肉"是规矩 |
| **豆腐坊** | 本钱小 | +4 | −2（起早） | 两间铺 | 无。**但它是唯一能"每天见到所有人"的行当** |
| **药铺伙计** | 识字 | +5 | −1 | 坐堂 → 自己开号 | 医官、狱医；知道谁病了，就知道谁要倒了 |
| **私塾先生** | 童生以上 | +4 | −1 | 塾师 → 山长 | 门生。你的学生将来可能做主官 |
| **媒婆** | 人情 | +5 | −1 | 官媒 | 全城的姻亲网在你手里，这是硬通货 |
| **稳婆** | 胆 + 手 | +4 | −2 | — | 知道谁家添丁、谁家打胎。**最危险的一门知道** |
| **扎纸匠** | 无 | +3 | −1 | 纸扎铺 | 丧仪：谁家死了人、谁家出不起丧钱 |
| **当铺朝奉** | 眼力 | +7 | −1 | 二柜 → 掌柜 | 谁在当东西，谁就快倒了。这是全城最早的经济情报 |
| **衙前书吏（白役）** | 识字 + 人情 | +6（陋规为主） | −2 | 书办 → 典史 | **半只脚踏在官场里**：不是官，但所有公文都过他的手 |

**设计要点**：平民线的"官场接口"就是**陋规**。你不在体制内，但每一件事都有你的份子——这是 1566 式的真实：**官府的每一两银子，都要经过十个平民的手，每个手都要留一点。**

## 5. 轨：你不扮演谁，你成为谁

### 5.1 三个前提

1. **起点是同一个。** 同榜进士、同一间翰林院。这正是 1566 的结构：严嵩、徐阶、高拱、张居正、海瑞，都是从这套系统里出来的，起手的差别并不大，分岔全在**事上**。
2. **你不选"我是谁"，你在事上选边。** 选得多了，系统才认出你是谁。轨不是职业，是**史书会把你归到哪一本传里**。
3. **可以一生不入任何一轨。** 那就是「无传」——它可能是最高评价，也可能是最惨的一种。

### 5.2 定轨：三个节点 + 无数次站边

轨不是"转职"，是**被归位**。三条硬节点：

| 节点 | 时点 | 选什么 |
|---|---|---|
| **散馆** | 第 3 年 | 留馆（清贵）/ 外放（实务）/ 改庶吉士（再等） |
| **第一次签字** | 第 6–8 年 | 一件要你担责的事，你怎么签——第一次暴露取向 |
| **一方大员 / 入阁前** | 第 15–20 年 | 轨已成型，只剩"守不守" |

中间还有无数次**站边**：弹章站谁、变法站谁、座师倒了你说不说话、同年被参你递不递话。每次站边给若干轨加分，分最高者为当前轨。

**允许漂移，但漂移有价**：改轨一次，誉 −8，旧同党视你为叛（此后所有"托人"判定 −15）。**明代官场最恨的不是敌人，是改过主意的人。**

### 5.3 六条轨（五显一隐）

| 轨 | 生态位 | 你会反复做的事 | 禄 | 誉（清/能） | 寿 | 室 | 一句话 |
|---|---|---|---|---|---|---|---|
| **清流** | 言官、讲学、修史 | 上疏、弹人、辞官 | 低（三品即顶） | 90 / 40 | 中 | 冷 | 骂得越狠，升得越慢，名越大 |
| **能吏** | 钱粮、刑名、河工 | 算账、督工、平账 | 高 | 40 / 90 | 损 | 空 | 事办成了，人得罪光了 |
| **权臣** | 结党、柄国、替人办事 | 收人、许官、换手 | 顶 | 20 / 85 | 极损 | 散 | 你替所有人办事，直到没有人替你 |
| **边臣** | 军务、外交、封疆 | 调兵、议和、守城 | 中高 | 65 / 75 | 大损 | 远 | 胜则名将，败则罪臣，中间没有第三种 |
| **循吏** | 地方久任、教化 | 修渠、办学、不断案 | 低 | 75 / 60 | 高 | 暖 | 一县之人给你立祠，朝廷不知道你的名字 |
| **孤臣**（隐） | 无党、无室，只对上与民 | 独奏、独行、得罪所有人 | 中 | 95 / 70 | 损 | 0 | 你没有软肋，所以谁都不敢用你 |

**隐轨的开启条件**：室 = 0（无室档）或主动断党（一次性弃掉全部"人情"资产）。二者都不可逆。

### 5.4 每条轨都缺一项（这是设计的核心）

| 轨 | 缺的那一项 | 具体机制 |
|---|---|---|
| 清流 | **禄** | 禄 上限 55；越有名越升不上去（清誉 >80 时升迁 −15） |
| 能吏 | **誉（清）** | 清誉上限 60；每办成一件大事，清誉 −5（"他的钱哪来的"） |
| 权臣 | **寿 + 室** | 寿 年损 +2；室 上限 50；一朝倒台，禄财誉三项同时归零 |
| 边臣 | **寿 + 室** | 寿 年损 +3；每三年一次"战/和"判定，败则寿 −15 |
| 循吏 | **禄** | 禄 上限 45；但「誉」在地方上可破 85（一县之祠） |
| 孤臣 | **室** | 室 恒为 0；但五项上限 +5、每年多 2 格 |

> **没有一条轨是"全能"的。** 玩家真正在选的不是"我想当什么官"，是"我愿意缺哪一项"。

### 5.5 史评：死后你被写进哪一本传

死亡不是结束。**死后三年**，史评定型——这三年里，你的门生、你的敌人、你修过的堤、你烧掉的册子，都还在说话。

| 笔法 | 条件 | 判词样例 |
|---|---|---|
| **本传** | 轨成型 + 誉 ≥70 + 有一件"不可抹去的事" | 「某某，字某，某地人。少孤，力学。」 |
| **附传** | 党籍明确（权臣/某一党的核心） | 「某某，某人之党也。附见其传。」 |
| **循吏传 / 酷吏传** | 循吏轨 / 能吏轨且手段酷烈 | 「所至有能名，民畏之，亦思之。」 |
| **佞幸传 / 奸臣传** | 权臣轨 + 墨 ≥60 | 「善伺上意，天下侧目。」 |
| **无传** | 未入任何轨，或誉 <30 且无门生 | 「时同僚有某者。」——一行，没有名字 |

**最阴的一笔**：「门生」这一项直到死后才结算。你活着时不肯提携后进（省了人情、省了钱），死后就没有人替你说话——**你的一生，由你生前最不在意的那几个人决定怎么写。**

### 5.6 与历史人物相遇的规则

- 历史人物**有固定的算盘**，不改写。他们按自己的逻辑走，不会因为你是主角就绕路。
- 你会与他们**同路**或**挡路**：同路得分（援、保、举荐），挡路被清算（但有时间差，往往三年后才动手）。
- 系统**从不告诉你**"这是严嵩"。只给一个姓、一个官称、一句口头禅。认得出来的人，心里会一惊；认不出来的人，照样被吃掉。
- "你成为了历史中的谁"由史评回答，答案有四种：
  1. 「与某某同传」——你和他是一路人。
  2. 「附于某某传后」——你在他影子里。
  3. 「某某一生的对手，是他」——你没有独立传，但每个读史的人都会记住你。
  4. 「无传」。

### 5.7 为什么不做"扮演历史人物"

- **扮演 = 已知结局。** 玩家会照着"海瑞最后被罢官"的最优解走，game over 变成打卡。
- **选择 = 未知归属。** 玩家不知道自己的选择会把他归到哪一本传里，才会真的犹豫。
- 1566 的乐趣从来不是"我是海瑞"，而是"**我在那个位子上，会怎么做**"。

### 5.8 同榜：你的敌人多半是同年

开局生成 3–5 个同榜进士（NPC），一生纠缠。机制很轻，但很毒：

- 同年有难，你不救 → 「凉薄」标记，同党的"托人"判定 −10；
- 同年升得比你快 → 每年一次「比较」事件，寿 −1（心气）；
- 同年里必有一个将来要整你的人，且**开局就能看出苗头**（他说话时总在替别人留余地）。

> 明代的党争，大半不是忠奸之争，是**同年、同乡、同门**三张网在互相勒。

**同榜十二人（示例，开局即生成，各自按自己的算盘走）**

| 同榜 | 出身 | 第 3 年（散馆） | 第 15 年 | 第 30 年 | 史评 |
|---|---|---|---|---|---|
| 陆某 | 寒门 | 外放知县 | 户部主事 | 巡抚，抄家 | 能吏传（附） |
| 沈某 | 官宦 | 留馆 | 通政使 | 首辅，夺谥 | 奸臣传 |
| 周某 | 书香 | 御史 | 削籍归里 | 讲学，门生满天下 | 本传 |
| 顾某 | 商人子 | 县丞 | 知府（久任不升） | 致仕，一县立祠 | 循吏传 |
| 冯某 | 军户 | 兵备道 | 总兵 | 战死 | 本传（忠义） |

最后一行是设计里最冷的一笔：**同榜里总有一个从不犯错、也从不被记住的人。** 他的六项可能都在 60 上下——你要不要成为他，是你自己的事。

## 6. 官场事件：1566 法

### 6.1 五条方法论

**① 局先于人。**
先问"这件事里，谁最想办成、谁最怕办成"，再看谁说了一句什么话。台词永远是**手段**，不是信息。

**② 期限即刀。**
所有事件都有期限（3 / 6 / 12 月令）。没有期限的事不是事件，是背景。上头从不给你方案，只给你期限。

**③ 签字的人。**
每件事最后都要一个人落笔。**"谁签"比"怎么做"重要**——玩家真正在选的是"这一笔让谁担"。

**④ 话有三层。**
- 字面：请示
- 实指：你担不担
- 威胁：你家里几口人

同一个 NPC，第二次说同样的话，含义已经变了。

**⑤ 事后账。**
事件结束不结算，1–3 年后才回响。怨、恩、把柄都记在册子上，不显示给玩家。

### 6.2 事件的三层结构

```
局  ← 谁要什么（三个以上的人，三种互不相容的"对"）
人  ← 四到六个活人，每人一句台词、一个把柄、一条软肋
刀  ← 期限 + 谁签字
```

### 6.3 示范事件 A：改稻为桑（县丞视角）

> 上头要丝绸换银子填库，府里要三十万亩桑田，县里要"不激变"，百姓要活过今年。
> 桑苗三年才见钱，而今年的租，秋后就要交。

**人**

| 角色 | 要什么 | 台词 | 把柄 |
|---|---|---|---|
| 知府 | 三年内出丝，政绩 | 「朝廷的难处，你不是不知道。」 | 他儿子在京城候补，缺一笔打点 |
| 巡抚 | 银子，最快的那种 | 「我不要过程，我要数。」 | 他去年的河工账，三成没入册 |
| 士绅（徐姓） | 田还是他的田 | 「祖宗留下来的，我不能做主。」 | 他家长子去年买了个监生，名字是假的 |
| 里长 | 人头上交够，别出事 | 「报多少，您说个数。」 | 他替三户人家瞒了丁 |
| 老农（陈四） | 今年有稻吃 | 「桑叶不能当饭。」 | 无。**他没有把柄，这是他唯一的力量** |

**刀**：三个月内报亩数；报册由县丞（你）署名。

**四选一（每个都要有人受损）**

| 选项 | 潜台词 | 六项 | 一年后回响 |
|---|---|---|---|
| **强推**：按三十万亩报 | 先把数交上去，剩下的事明年再说 | 禄 +12、财 +8、誉 −12、室 −6 | 陈四家的田被划走，成了流民；县里多了一百二十个"无籍" |
| **缓推**：报十万，逐年增 | 拖，是最像办事的不办事 | 禄 −6、寿 −4、誉 +2 | 知府记你一笔；但今年没人饿死 |
| **借商**：让徐家先垫，以丝偿 | 把官府的难处，卖给有钱人 | 财 −10、禄 +6、誉 −4、**墨 +10** | 徐家从此在县里说话比县丞响 |
| **上告**：把三本册子的差报给御史 | 你不做官，也要做个人 | 誉 +8、禄 −20、寿 −8 | 御史查了，你也调了。三年后有人替你说话，或者没有 |

**这一折教什么**：陈四没有把柄，所以他是唯一不能被你"搞定"的人。**这就是为什么真正的难处，永远在最没有力量的那一头。**

### 6.4 示范事件 B：清丈田亩

三本册子：**鱼鳞册**（真的）、**上报册**（假的）、**你手里那本**（半真半假）。

| 选项 | 六项 | 后果 |
|---|---|---|
| 照实丈 | 誉 +10、禄 −8、寿 −5 | 士绅联名上书；但十年后赋税真的均了 |
| 照旧册 | 禄 +6、墨 +8、誉 −6 | 一切顺利，直到下一任清丈 |
| 丈一半（先丈自己人的） | 禄 +3、誉 −3、室 +4 | 族里夸你会做人；百姓骂你 |
| 把三本册子抄一份给御史 | 誉 +12、禄 −30（险） | 40% 概率被反坐"构陷上官" |

### 6.5 示范事件 C：河工银

银子过三手：部拨 → 府库 → 县丞 → 工头。每一手都少一点，是规矩。

| 选项 | 六项 | 后果 |
|---|---|---|
| 一文不动，全给工头 | 誉 +6、财 −、禄 −4 | 堤修得慢；秋汛若垮，是你一个人的错 |
| 照规矩留一手 | 财 +12、墨 +8 | 堤修得快；三年后若垮，账上写着你的名字 |
| 把钱换成"以工代赈" | 誉 +8、财 −6、子 +2 | 灾民有饭吃；但工期拖到明年 |
| 把工头换了 | 禄 +4、誉 −2、寿 −3 | 新工头是你的人；旧工头会去别处说你 |

**这一折的核心**：**堤修好了没人记得你，堤垮了只有你。** 所有工程类事件的定价都一样——功劳归上头，责任归署名的人。

## 7. 情关

### 7.1 三轴

| 轴 | 含义 | 变化 |
|---|---|---|
| **情** | 她对你 | 由共处月令、事件选择改变，每年自然 −2（不维护就淡） |
| **义** | 你欠她 | 只在你负她时上涨；义 ≥60 会强制打开一次"对质" |
| **时** | 窗口 | 剩余年数。**过期作废，永不复开** |

**情关只开一次。** 每段感情有 1–3 年窗口；窗口一过，那个人就嫁人、调走、病了、死了。这一条是全作最狠的机制——**不是"你选错了"，是"你没来得及"**。

### 7.2 四种情关

#### A. 你爱她，她不爱

**判定**：`情(她) < 40` 且 `你的 财+誉+门第` 低于她的择偶线。

| 结果 | 条件 | 后果 |
|---|---|---|
| 成（少数） | 情 ≥60，且共同经历过一次"患难"事件 | 室 80；但她心里那个人不是你，室 上限 85 |
| 半 | 情 40–60 | 她应了。室 60，且每年 −3（"她待你好，只是不像你待她"） |
| 败（多数） | 情 <40 | 留下 **「念」**：此后每年她生日，寿 −1；二十年后有一次重逢，可选"见 / 不见" |

> 「你很好。可我一想起你，想到的是你对我的好，不是你。」

#### B. 她爱你，你不爱

**判定**：`情(她) ≥ 70`，`情(你) ≤ 30`。

| 结果 | 后果 |
|---|---|
| 娶 | 室 60（她肯将就），情 不涨。多年后她病，你在任上 |
| 不娶 | 留下 **「负」**：她嫁人后，每逢你升迁，会有一封信或一句话到。若此后终身不再议亲，转入**「无室」档**，孤臣轨开启（见 1.1、§5.3） |
| 拖（最坏） | 拖过窗口：她自尽 / 远嫁 / 出家，各 1/3；誉 −10，且"负"加倍 |

> 「我知道你不喜欢我。我就是想再等一年。」

#### C. 两情相悦 → 变心

**判定**：双方 情 ≥70，但满足任一——
- 时 耗尽（3 年未定）
- 禄 的诱惑（另一门亲事带来 禄 +15）
- 你连续两年"私事格"为 0（她认定你不会有空）

| 结果 | 代价 |
|---|---|
| 挽回 | 财 −20，或 禄 −10（求人调回本地） |
| 放手 | 留下 **「疑」**：此后所有情关判定 −10 |
| 被弃 | 誉 −10、室 0；她家成为你在官场上的一个"敌对关系"（永久） |

> 「不是他比你好。是他来得比你早一点——在我还等得起的时候。」

#### D. 两情相悦 → 现实压力

**四种压力源**：门第（差 ≥2 档）、异地（调任 / 进京）、父母（孝）、钱（彩礼 / 房贷 / 家用）。

**判定**：`压力值 ≥ 情 × 0.6` 时触发。

| 结果 | 代价 |
|---|---|
| 扛 | 寿 −5/年，财 −；但室 90+，且子项 +10 |
| 放 | 室 0；留下 **「债」**：多年后她家的关系会挡你一次，或帮你一次（五五开） |
| 私奔 / 辞职 | 禄 归零；但"另起一行"：财从 0 起，寿 +5，誉 −8（"不成器"） |

> 「我不怕穷。我怕你将来怨我。」

### 7.3 情关的"锁"

每过一次情关（无论成败），六项中有一项被**锁上限 70**：

| 情关 | 锁 | 理由 |
|---|---|---|
| A 你爱她她不爱 | 寿 | 「念」伤身 |
| B 她爱你你不爱 | 誉 | 「负」损名（乡里会议论） |
| C 变心 | 誉 | 「疑」使人刻薄，刻薄者无清誉 |
| D 现实压力 | 禄 | 「债」在官场上会替你选一次，你就不自由了 |

> 这是"情关"与"六事"唯一的硬连接：**情关不过，六事缺一。**

### 7.4 室位唯一，但婚配只是五条路之一

- **「室」100 分只对应一个"回去的地方"**。五条路径（婚配/孝养/义子/挚友/门生）可叠加，取最高 + 其余各 1/3，不重复计算。
- **婚配是正统，不是必需**。三个入口可以不娶：
  1. 16 岁议亲时直接选「不议亲」（此后每年可改，但可选对象的质量逐年下降）；
  2. 情关 B 选「不娶」；
  3. 情关 D 选「放」，此后不再议亲。
- **独身 = 「无室」档**（见 1.1）：不参与结算、其余五项上限 +5、每年多 2 格、解锁「孤臣」轨。它不是失败，是**另一种算法**；但六十岁以后，每年会有一次「独坐」事件提醒你，你换掉的是什么。
- **纳妾不增「室」**。明代士大夫纳妾是常态，但那是"人丁"不是"家室"：妾只影响「子」（添丁概率 +），并让 誉 −2/年、室 −3/年（她在那个人面前抬不起头）。**这是全作唯一一个"花钱买子"的选项，也是最脏的一个。**
- **同时维持两段关系**（不论婚否）：室 上限锁 55、誉 −3/年，"风声"槽满 → 对质局，随后必有一次弹章（"帷薄不修"）。
- **断线不可接**：一旦「疑」或「债」落下，即使复合，室 永远 ≤70。

## 8. 时间、死亡、结算

| 项 | 规则 |
|---|---|
| 一岁 | 12 月令（四季各 3）；寿 <30 时降为 9 格；无室 +2 格 |
| 起局 | 16 岁（可议亲、可入行；也可直接选"不议亲"）。**生在哪一年由掷定**：古代 1494–1594（嘉靖前后百年），现代 2020–2032（见 §2.6） |
| 入仕 | 20 岁起可考；每三年一科 |
| 婚龄窗口 | 女 15–22，男 17–28；过了窗口，可选项断崖式下降（但不会归零——四十五岁仍可娶寡妇或续弦，只是没有"情分底子"） |
| 定轨 | 第 3 / 6–8 / 15–20 年三个节点，其余靠站边累计 |
| 死亡 | 寿 = 0；或触发"病"事件判定失败 |
| 死亡不是失败 | 死亡才结算。且「誉」在死后继续发酵——**三年后史评定型**，门生多寡在此刻生效 |

**寿是沙漏，不是血条。** 每年自然 −1；劳累、赴任、伤心各自额外扣。玩家看到寿在减少，但他停不下来——这是设计要的。

## 10. 文案规范

### 10.1 三层话

| 时代 / 场景 | 语体 | 例 |
|---|---|---|
| 官场（明清） | 半文半白，敬语为壳，威胁为核 | 「朝廷的难处，你不是不知道。」 |
| 市井 | 白，短，带物件 | 「桑叶不能当饭。」 |
| 当代 / 企业 | 标准现代汉语，短句，多留白 | 「这个数，我担不了。」 |

### 10.2 四条硬规则

1. **不写心理活动**，只写动作与物件。「他把茶碗推回你面前，说'凉了'」比「他很生气」重十倍。
2. **不写善恶判断**，只写代价与时限。
3. **每个选项都要有一句说得过去的理由**——否则玩家会觉得游戏在教他做人。
4. **强者的话短，弱者的话长。** 陈四会解释三句，知府只说四个字。

### 10.3 官场对话的三个层次（写台词时的检查表）

```
第一层（字面）：他在请示。
第二层（实指）：他在问"这一笔谁签"。
第三层（威胁）：他知道你家里几口人。
——三句话里，只要有一层没写出来，这段对话就是废的。
```

## 附：一局示范（三十年为度）

**出身**：军户（禄 20、寿 58、无门第）

**第 1–5 年**：从行伍做起（月令 8 格在营，4 格给寡母）。存 财 到 30。与邻家女（情 45）议亲，门第差 1 档，成了 —— 室 65。
**第 6 年**：调防令下（宿命线）。选「携母赴任」：财 −20、室 −10、禄 +8；选「留母在原籍」：室 +5、寿 −6、每年一次"家书至"。
**第 9 年**：河道总督衙门要一个懂营造的（匠户底色 +15），你补了缺 —— 禄 +15，但从此每年只有 2 格在家。
**第 12 年**：河工银那一折。你选了「以工代赈」：誉 +8、财 −6、子 +2。三年后堤没垮，也没人提你的名字。（**能吏 +15**）
**第 18 年**：儿子科考，榜上有名，而你弟弟是誊录（科场舞弊那一折）。此时 禄 55、誉 60、室 40、子 70、财 45、寿 42。
**第 24 年**：她病了。任上走不开。回，禄 −12；不回，室 归 0，且「负」落定。
**第 30 年**：卒。寿 归 0。

结算：`min = 室(0)`。轨：**能吏**（治河三折全走实务，未改过轨）。

> 墓志：「某某，军户出身，官至按察副使。治河二十年，堤未溃。妻某氏，先卒。」
> 别人记住你的方式：**「堤未溃」**。
> 你自己是什么人：**签**。
> 史评：**附于《河渠志》后**——没有本传，但每一个查河工的人都会读到你的名字。

**若换一个人走**：同一起点，第 3 年散馆时选了"留馆"，一辈子没外放；三次弹章都"反参"；六十岁做到尚书，抄家，无子，无室。
结算 `min = 室(0)`——但这次是**孤臣**轨，六事按五项算，`min = 子(0)`。
> 墓志：「某某，翰林出身，官至尚书。无子。」
> 史评：**《佞幸传》，附于某权臣传后。**
> —— 两个人，同榜，同一年死。一个被写进《河渠志》的注里，一个被写进《佞幸传》的末尾。

**这一局若出命书**（八字：丙午 · 甲午 · 丙寅 · 己丑）：言 95、智 78、忍 78、体 58、巧 58、缘 60。

史评说他是**能吏**，命书说「你本是言官的材料」。他治河二十年，靠的不是「巧」（58，缺金水），是「忍」（78）——**他不是天生的河工，他是熬出来的河工。**

而第二个人，八字**一模一样**：只把「言」练到了顶。同一句话，一个拿来劝人，一个拿来许官。**这就是"五世同一个八字"要证明的事——命不改，人改。**

*本框架可与《仕途五百年》视觉与交互方案对接：六项对应六枚印（名权家心 → 誉禄、室、财、子、寿），墨渍与墨值沿用同一套视觉语言；「轨」可做成一枚随年份变换的闲章——清流是"直"、能吏是"干"、权臣是"柄"、循吏是"守"、孤臣是"独"、无传是空白。**八字这一层单独一页"命书"：全墨、竖排、一方朱印，与正片的六印并置时，正好是"命"与"人"对望。***
