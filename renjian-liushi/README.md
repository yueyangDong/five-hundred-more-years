> 室、财、子、禄、寿、誉。六事皆求，终不能全。
> 五世只给你**一个八字**。第一世你看不见它，第五世它才开口。

## 三条核心规则

**一、六事取 min，不求和；而且这六样你看不见。**
一岁十二个月令，每件事都要占格。所有"无法兼得"最终都能还原成"今年这十二格，你给了谁"。结算不看你赢了多少，只看你最薄的那一块。

左栏六行只有虚线——**数字、彩条一概没有**，加减只报 ↑/↓。只有**任意一格推到了你的顶**（上限，或 100），才会「透」：六事俱明，全盘亮起。看清自己的唯一方式，是把一件事做到没人能装作没看见。

而"顶"不是人人一样高：**官宦人家的禄顶 80，罪臣之后 30；市井无禄的人，这一格压根不存在。** 官宦三十九岁做到他父亲那一级的那天，也就是他的「透」。没有位子的人不按禄结算——他不是缺了那一格，是没有那一格。

**二、五世同一个八字，古或今不由你挑。**
八字在开局前**由你自己填生辰排出**（年柱以立春分界、月柱以节气分界、日柱按儒略日直推），跨局锁定——不随出身、时代、职业改变。不想填也可以让系统随便给一副。变的只有壳：生在哪家、生在哪年、你选了哪条路。古代窗口取**嘉靖前后各五十年（1494—1594）**，以嘉靖五年（1526，丙戌）为卷首之年；现代取"现在"（2020—2032）。每局独立掷，但**五局古今各不少于二**。

**生在哪家，也不是你挑的。** 十二种出身随机一张牌，揭开来是什么就是什么——能挑，就会退化成难度选择，而"这局抽到了罪臣之后"才是它该给你的东西。

**三、第一世看不见自己。**
六才（智、体、言、巧、忍、缘）永不以数字示人。你只能从"事办得顺不顺"里反推，而反推出来的印象记在**手记**里——**手记可能是错的**。第五世结算，命书才开。

## 玩

直接用浏览器打开 `index.html`。存档在 localStorage，`清卷` 可重来。**声音默认开着，但浏览器要先等你点一下**——第一次点击之后才有声；右下角的 `音` / `静` 可随时关。

- **排命**（填自己的生辰，排出四柱）→ 掷局 → **投胎**（生在谁家，由不得你挑）→ 每折（四年）选一项 → 局末得三句手记 → 五局毕出命书 → 摸到自己的顶，可窥天机

## 原型范围

**已实现**：八字排盘（年柱以立春分界、月柱以节气分界、日柱按儒略日直推、时柱五鼠遁）、六才隐藏成长、**六事全隐与「透」（一格到了你的顶才全亮）**、五局随机古今、六事与月令、**五十四条事件（古今两套文案、每条三选项一记手记）**、**子的五级台阶（有后/立业/有孙/家和/四世同堂）、誉的一极即满与方外之路、律的暗线（问拟/立案、首告、出家）**、三关、手记（含"错误的记忆"）、命书、天机、改史与跨世已知、**三记音效（掷局/透/卒，WebAudio 现场合成，右下角可关）**、单机存档。

**这一版新接的三套机制**（此前只在设定里）：

- **职业三条轴 + 市井十二行**（§4）。十八个行当各有自己的每折流量：文官升得快而家里空，军职命是国家的，商人的财是攒出来的，市井的人只有一双手和每天少一点的力气。禄 = 组织授予的位置，**无禄的人财与誉上限各 +10**，代价是任何一件官面上的事都没有"位"可挡。
- **六轨**（§5）。不是转职，是**被归位**：你在事上选边的痕跡被归一化后比较（替人办事的机会到处都是，独奏独行的机会很少，所以机会多寡要折算掉）。**每条轨都缺一项**——清流缺禄、能吏缺清誉、权臣缺寿与室、边臣缺寿与室、循吏缺禄、孤臣缺室。改轨一次誉 −8；孤臣要先"无室"或"断党"。
- **史评五笔法 + 情关四种**（§5.5、§7）。本传／附传／循吏·酷吏传／佞幸传／无传，按轨与墨定；**「门生」到死后才结算**——你活着时不肯提携后进，死后就没有人替你说话。情关有 A/B/C/D 四种、三轴（情／义／时），**情不出数字**，你只能从回信的字数里猜；窗口过期作废，每种关都会锁掉六事里的一项上限 70。

**未实现（见设定框架 §11）**：同榜 NPC 党争网与"三年后才动手"的时间差、满招损反噬、同时维持两段关系的对质局、事后账簿的三年回响。

**原型数值为示意**，正式版需逐条配平。排盘为简化算法（日柱随机取值），接真实节气与万年历是正式版的事。

## 设计上两处被原型推翻的规则

1. **寿不参与 min**。寿归 0 就是死，不是"缺寿"；若把 0 算进 min，每个结局都是"空"。
2. **天机不是"必须 95"**。按八字规则能出现 95 的命只占 9%，改成"**摸到自己的顶**（上限 ≥78）"，才不是抽奖；95 那一格只多一行朱批。
